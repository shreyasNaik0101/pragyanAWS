The local RSA signing pair is prepared. Only the public PEM is in ignored `artifacts/aws-media-public.pem`; the private PEM is in ignored `.local/aws-media-private.pem` and must be installed into the created Secrets Manager secret after deployment. The private key must never enter a repository or terminal output. The reviewed renderer trust/policy JSON is under ignored `artifacts/`.

Deployment order after explicit approval: create the manual Amplify app to get its exact HTTPS origin; create the reviewed renderer role and deploy its trusted bundle/function; synthesize and deploy the CDK stack with the origin, public key and renderer identifiers, initially with exports disabled; install the signing secret; build the static site with actual API/Cognito outputs; upload it through Amplify; invite a Cognito user; run low-cost smoke checks; enable only the approved three-export pilot. CDK intentionally **retains** the DynamoDB table, media bucket and Cognito pool; separately inspect and explicitly delete them, remaining logs/secrets and CDK bootstrap assets if full shutdown is desired. Check Billing afterward. No broad account cleanup command is part of the plan.
