Problem Statement

When a student is stuck on a concept at 11 PM, they have no way to get a quick, visual, language-friendly explanation. Existing tools give either 400 words of English text (ChatGPT) or a 2-hour pre-recorded lecture (Byju's) — neither addresses the specific doubt, in their language, right now.

The 3 Gaps No One Has Solved Together
  • ⏱ Time Gap: Students need answers NOW — not a 20-min lecture for a 1-minute doubt. Teachers handle 40-60 students; they can't give 1-on-1 attention at scale.
  • 👁 Visual Gap: STEM concepts (Fourier Transform, DNA replication, BFS algorithm) cannot be understood from text alone — they need animated visual explanations.
  • 🗣 Language Gap: 50%+ Indian students think in Hindi/regional languages, but every AI tool (ChatGPT, Gemini, Khan Academy) responds only in English.

📌 Our problem is NOT "replacing teachers." It's: "When the teacher isn't available, how does a student get a quick visual explanation of their specific doubt, in the language they think in?"

Theme: AI-Powered Inclusive & Accessible Education

02

Proposed Idea / Solution

Gyan Pragyan generates custom 1-minute animated explainer videos with voiceover in the student's language — on-demand, for any concept, in ~30 seconds. It's a doubt-clearance engine, not a lecture replacement.

Core Innovation: Generate, Don't Search
  • AI Video Generator: Type any concept → get a focused animated video with domain-aware visuals (equations for math, diagrams for biology, code for DSA) in ~30 seconds
  • Multi-lingual TTS: Videos narrated in Hindi, Hinglish, Kannada, Marathi, English — powered by Sarvam AI
  • WhatsApp Bot: Send doubt on WhatsApp → get AI explanation + video back. No app download. Works on any ₹5K smartphone
  • YouTube Summarizer: Paste any lecture URL → get timestamped AI summary + PDF notes (complements the 1-min video)
  • AI Chat Assistant: Conversational doubt-solving with context memory — follows up across messages
  • Photo Solver: Upload a photo of any problem (handwritten/textbook) → get step-by-step solution

🔗 1-min video clears the doubt + YouTube links provided for deep-dive — best of both worlds.

03

Methodology / How It Works

End-to-End Pipeline (Doubt → Video in ~30s)
Student Doubt→ Intent Engine→ LangGraph Supervisor→ Specialist Agent

Script (GPT-4o)→ TTS (Sarvam AI)→ Render (Remotion)→ Deliver (Web / WhatsApp)
Key Technical Stages
  • Intent Classification: Multi-agent LangGraph supervisor routes each query to the right team (Visual / Math / Coding / Video)
  • Domain-Aware Script: GPT-4o generates structured scripts — physics gets equations, biology gets diagrams, DSA gets code blocks
  • Parallel TTS: All narration segments synthesized simultaneously via Sarvam AI / OpenAI
  • Pipelined Render: Webpack bundle, script generation, and TTS overlap in parallel — Remotion renders at 2x concurrency with optimized encoding
  • Smart Caching: Same topic+language → instant response from disk cache (no re-render)

Why 1-Min Videos Work

We don't replace lectures. We clear specific doubts — then link students to full resources for deep learning.

The Science
  • Cognitive Load Theory (Sweller, 1988): Short visual bursts reduce extraneous load → better retention
  • Multimedia Learning (Mayer, 2009): Words + pictures > words alone
  • Microlearning: 1-min focused content has 3x higher completion rate than 20-min lectures
Our Approach
  • 1-min video → clears the immediate doubt
  • YouTube links → provided for full deep-dive
  • AI Chat → follow-up questions answered
